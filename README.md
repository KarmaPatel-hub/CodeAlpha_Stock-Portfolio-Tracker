# Stock Portfolio Tracker

A simple Python project created as part of my Python Programming Internship at CodeAlpha.

This application allows users to enter a stock name and quantity to calculate the total investment value based on predefined stock prices.


## Features
- User-friendly console interface
- Predefined stock prices
- Calculates total investment value
- Displays investment details clearly
- Beginner-friendly Python project


## Technologies Used
- Python


## Concepts Used
- Dictionaries
- If-Else Statements
- User Input Handling
- Arithmetic Operations
